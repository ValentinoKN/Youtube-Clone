## About the Project

This YouTube clone was created as part of my learning and practice with HTML and CSS while working through SuperSimpleDev's course.

The course uses a YouTube-style project to teach how increasingly complex interfaces can be built from fundamental HTML and CSS concepts. The project is developed progressively through the later lessons and culminates in completing the interface and applying additional CSS features and responsive-design concepts.

- CSS Grid
- Flexbox and nested Flexbox

- Responsive design
